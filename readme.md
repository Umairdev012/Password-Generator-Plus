/# 🔐 Password Generator Pro

A modern and secure **Password Generator Web App** built with **HTML, CSS, and Vanilla JavaScript**.  
It allows users to generate strong passwords with custom options like uppercase, lowercase, numbers, symbols, and length control.

---

## ✨ Features

- 🔐 Generate strong random passwords
- 📏 Adjustable password length (6–24)
- 🔡 Include uppercase letters
- 🔤 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special symbols
- 📋 One-click copy password
- ⚡ Auto-generate on load
- 📱 Fully responsive design
- 🎨 Clean modern UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
